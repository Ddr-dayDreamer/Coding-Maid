## 决策记录

| 决策 | 结论 | 理由 |
|------|------|------|
| 框架选型 | **Svelte 5** | 零运行时、VS Code 生态标准、可增量迁移 |
| 通信模式 | **保留推送 + 叠加 request/response** | 聊天场景推送高效，编辑场景 request 精确 |
| 预设切换位置 | **composer footer 左侧** | 输入时直观可见、切换立即生效 |
| 页面切换 | **前端 Tab（非 VS Code tab）** | 同 webview 内切换无延迟 |
